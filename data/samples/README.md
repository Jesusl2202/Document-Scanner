# Ejemplo sintético

`synthetic_receipt.png`, su PDF y `synthetic_gold.json` son datos ficticios para comprobar la instalación. No pertenecen a SROIE ni WildReceipt. El identificador no representa una persona o empresa real y no es un RUC validado.

Sus aciertos no se usan en las métricas del proyecto. Para samples reales, descargar las bases desde las fuentes documentadas y seleccionar IDs del manifiesto conforme a sus condiciones de uso.
