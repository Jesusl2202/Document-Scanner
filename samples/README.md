# Samples

Esta carpeta se reserva para ejemplos pequeños que permitan probar el pipeline.

## Importante

No se deben subir aquí datasets completos de terceros sin verificar sus términos de uso.

Para el proyecto se recomienda utilizar:
- muestras sintéticas;
- comprobantes RIDE propios totalmente anonimizados;
- ejemplos de datasets públicos únicamente cuando su licencia permita redistribución.

Los datasets completos deben descargarse desde sus fuentes oficiales o de referencia.
