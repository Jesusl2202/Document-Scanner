# Licencias y permisos

Este archivo registra el estado preliminar de licencias y permisos de los datos utilizados.

## SROIE
Uso previsto: académico y experimental.
Antes de redistribuir imágenes originales en este repositorio, revisar los términos de la fuente concreta desde la que se descarguen.

## WildReceipt
La documentación utilizada en el proyecto no establece de forma suficientemente clara una licencia propia del dataset para su redistribución.
Por ello:
- no incluir el dataset completo en GitHub;
- enlazar a la fuente;
- verificar las condiciones antes de añadir imágenes o anotaciones.

La licencia Apache 2.0 del repositorio MMOCR corresponde al software de MMOCR y no debe asumirse automáticamente como licencia del dataset WildReceipt.

## DocILE
Usar mediante el procedimiento de acceso definido por el proyecto oficial.
No redistribuir sus documentos salvo que sus términos lo permitan expresamente.

## CORD
El repositorio oficial declara licencia Creative Commons Attribution 4.0 (CC BY 4.0).
Debe mantenerse la atribución correspondiente.

## Muestra propia RIDE
Los comprobantes pueden contener datos sensibles o identificables.
Antes de subir cualquier ejemplo:
- eliminar nombres, direcciones, correos, teléfonos u otros datos personales;
- evaluar si debe ocultarse la clave de acceso;
- utilizar preferiblemente comprobantes ficticios o expresamente autorizados.

Este documento es un registro académico y no sustituye una revisión jurídica.
